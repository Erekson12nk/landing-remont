# «Квадрат» — лендинг ремонта квартир (концепт)

Демонстрационный одностраничный сайт для вымышленной компании «Квадрат», которая делает ремонт квартир под ключ в Москве. Проект сделан как пример работы для портфолио: компания, цены и контакты не настоящие.

## Что есть на странице

- **Липкая шапка** с навигацией, кнопкой телефона и мобильным меню (бургер, закрытие по Esc).
- **Первый экран** с оффером, двумя CTA и ключевыми гарантиями.
- **«Что входит»** — сетка из 8 услуг с иконками.
- **Калькулятор стоимости**: ползунок и поле площади (20–200 м²), тип ремонта (косметический / капитальный / дизайнерский), дополнительные опции. Цена в рублях и ориентировочный срок пересчитываются мгновенно; расчёт можно одной кнопкой перенести в заявку.
- **«Как мы работаем»** — таймлайн из 5 этапов (вертикальный на мобильных, горизонтальный на десктопе).
- **Портфолио «до / после»** — интерактивные слайдеры сравнения с SVG-иллюстрациями интерьеров (без внешних фото).
- **Пакеты цен** — три тарифа; выбор тарифа подставляется в комментарий заявки.
- **FAQ** — доступный аккордеон (`aria-expanded`, `aria-controls`, `role="region"`).
- **Форма заявки**: имя, телефон с маской `+7 (___) ___-__-__`, комментарий, согласие. Валидация на клиенте и уведомление-тост об успехе. **Данные никуда не отправляются.**
- **Подвал** с пометкой «Концепт-проект. Компания вымышлена.»

## Особенности

- Mobile-first, корректно от 360 px без горизонтальной прокрутки.
- Семантическая разметка, подписи у полей, видимые состояния фокуса, ссылка «Перейти к содержимому».
- Плавная прокрутка и мягкие анимации появления; при `prefers-reduced-motion` анимации отключаются.
- Единая палитра на CSS-переменных: тёплый песочный фон, терракотовый акцент, шалфейный и графитовый.

## Стек

- HTML5, CSS3 (Grid, Flexbox, custom properties, `clip-path`), чистый JavaScript.
- Без фреймворков и сборки. Единственный внешний ресурс — шрифты Google Fonts (Unbounded и Manrope).

## Как открыть

1. Скачайте или клонируйте папку проекта.
2. Откройте `index.html` двойным кликом в любом современном браузере — сервер не нужен.
3. Для публикации на GitHub Pages достаточно загрузить содержимое папки в репозиторий и включить Pages: все пути относительные.
